# 🌿 漢方体質分析＆処方安全管理システム
**Kampo Constitutional Analysis & Integrated Guidance System**

漢方薬局でのカウンセリング業務、体質分析、処方選定、安全管理（生薬重複チェック）、および患者カルテ管理を、**サーバーやDB不要（HTML / 外部JavaScriptファイルのみ）**でブラウザ上で完結させる軽量な支援ツールです。

---

## 🚀 主な機能・特徴

1. **気血水・陰陽の総合体質分析**
   * 自覚症状チェックボックス（気虚・気滞・血虚・瘀血・水滞・寒熱）から各傾向をスコアリング。
   * **レーダーチャート**による多角的なバランス可視化と、おすすめ養生・処方群の自動提案。
2. **漢方四診パレット（舌診・腹診）**
   * 舌の色・苔・形態（淡白、紅、黄厚苔、歯痕など）や、腹証（心下痞鞭、胸脇苦満、臍下不仁など）の所見を視覚的に選択してレポートに反映。
3. **生薬重複・安全性チェック**
   * 主処方と併用処方を選択した際、過量投与や副作用リスクのある主要生薬（**甘草・麻黄・大黄・附子**など）の重複を自動検知して警告。
4. **煎じ薬・調剤分量計算機**
   * 処方と日数（例: 14日分、28日分）を選ぶだけで調剤指示を作成し、煎じ方の基本手順も自動添付。
5. **二十四節気・季節連動の養生アドバイス**
   * 相談日の日付から現在の五行（春の肝・梅雨の脾・夏の心・秋の肺・冬の腎）の季節特性を自動判定してレポートへ追記。
6. **カルテデータ管理（JSON入出力 & 過去比較）**
   * 患者名と年齢から自動生成されるファイル名（例: `山田太郎_45歳.json`）でカルテデータを保存・読込。
   * **過去カルテ比較（Before / After）**機能により、前回のレーダーチャートを赤点線で重ねて体質改善度を可視化。
7. **PDF直接保存 ＆ A4印刷対応**
   * ワンクリックでカルテレポートをPDF出力、またはA4用紙に最適化されたレイアウトで印刷可能。
